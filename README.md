# WoS Journal Abbreviation Scraper

> 📚 **A comprehensive mapping table for SCI Journal Full Names and Abbreviations.**
> Generated using AI (ChatGPT & Gemini) to bridge the gap between Impact Factor lists and citation data.

## 📖 Background & Motivation

This project was born out of a specific research need: **Linking Impact Factors (IF) to Scraped Literature Data.**

In many academic workflows, we often encounter a mismatch:
1.  **Impact Factor Datasets:** Usually list journals by their **Full Names**.
2.  **Citation/Scraped Data:** Often use **Abbreviations** or non-standard naming.

To accurately map Impact Factors to the journals I was researching, I needed a reliable "Full Name ↔ Abbreviation" lookup table. While Web of Science (WoS) provides this list online, the HTML format is not readily usable for data processing.

**This repository provides the scraped, cleaned, and structured data to solve this problem.**

## 🚀 How to Use

### 1. For Quick Reference
Download **`wos_journal_abbrev.xlsx`**.
* Go to **Sheet 2 (`unique`)** to find the standard mapping used for matching Impact Factors.
* Use **Sheet 1 (`raw`)** if you want to inspect the original scraped entries.

### 2. For Developers (Python/R)
If you are building a tool, use `wos_journal_abbrev_unique.csv` to load the mapping table directly into a DataFrame.

### 3. Reproducing the Results
To run the scrapers yourself:

```bash
